Six things cross the edge with your cursor

Each one travels encrypted, straight between your two computers.

Mouse and keyboard

Typing follows the cursor, held modifier keys included. Ctrl+Alt+Home always brings it back.

Copied text

Copy on one computer and paste on the other straight away, in either direction.

Files and pictures

Copy files, folders or a screenshot, move across, and paste. Or send files from the window.

Whatever you are dragging

Hold a file, a link or selected text, push through the edge, and keep dragging on the other side.

Sound

Choose one computer's speakers. The others go quiet and play through it instead.

Browser pages

Push a browser window against the edge and the page it shows opens on the other computer.

Privacy

Nothing leaves your own network

There is no account, no cloud relay and no telemetry. Two computers pair once by showing the same six-digit code, which you compare with your own eyes.

Encrypted end to end
Every key press, file and sound packet, with keys that never leave the two computers.
Strangers are refused
A computer you have not paired cannot connect, even on the same Wi-Fi.

Three steps from download to one mouse

  1. Put the file on both computers

    Download the file for each computer and start it. On Windows it sits by the clock.

  2. Press Add a computer on both

    Check the two codes match, then press Codes match.

  3. Drag the screens into place

    From then on they find each other, and update themselves.

An early release. On Linux it needs an X11 session (not Wayland), has no icon by the clock, and things dragged across arrive ready to paste; the Linux file must be marked as a program before it starts. On Windows the program is not yet signed, so Windows asks you to confirm the first start, and its firewall asks once to allow it on private networks. Programs running as administrator, and games that lock the mouse, do not accept shared input.
